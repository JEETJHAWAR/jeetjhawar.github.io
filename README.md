# Jeet Jhawar — Portfolio

Netflix-inspired personal portfolio, streamed in monochrome with a touch of space.

**Live site:** deployed via GitHub Pages.

## Structure

- `index.html` — the whole site (single file: markup, styles, scripts)
- `images/` — campus photos and stock imagery (Unsplash, free license)
- `assets/` — downloadable resume (`Jeet_Jhawar_Resume.docx` — grey & white template, plus PDF)

## Editing

The site is a single static HTML file — edit `index.html` and push. No build step.

To update the resume download, replace the files in `assets/`.

## Local preview

```bash
python -m http.server 8741
```

Then open http://localhost:8741.
