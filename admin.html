Access

Changes are saved straight into the GitHub repository, so the page needs a GitHub token that only you hold. Create one at github.com/settings/personal-access-tokens/new: set Repository access → Only select repositories → jeetjhawar.github.io, and under Permissions → Repository permissions → Contents choose Read and write. Then paste it below. It is stored only in this browser (localStorage) — never in the repository.
